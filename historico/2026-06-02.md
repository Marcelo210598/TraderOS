## 📝 Decisões técnicas importantes
- **Indicator vs AddOn:** Indicator depende de gráfico aberto, é instável para captura global. AddOn é a solução correta para integração que precisa sempre rodar.
- **IsEntry/IsExit não confiável para trades manuais Apex:** a lógica correta é rastrear posição líquida e disparar ao fechar.
- **Config por arquivo > propriedade no painel:** mais prático — o usuário não precisa nem abrir o editor de código de novo se quiser trocar a key.
- Rithmic API direto e SQLite estão fora: Rithmic custa $125/mês por usuário; SQLite é "unsupported" pelo NT8 e quebra em updates.
- CSV import continua sendo o fallback universal (Tradovate, Rithmic R-Trader, Sierra) — integrar depois.
