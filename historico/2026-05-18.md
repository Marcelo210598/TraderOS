## 📝 Decisões técnicas importantes
- Usamos `@prisma/adapter-pg` porque Prisma 7 não suporta mais DATABASE_URL direto no schema
- shadcn Nova preset usa Base UI (não Radix) — sem `asChild`, usar `render` prop
- Next.js 16 renomeou middleware → proxy (`src/proxy.ts`)
- NextAuth v5 usa `auth()` server-side e `signIn`/`signOut` no client

## ⚠️ Problemas encontrados e soluções
- **Prisma 7 breaking change:** `url` removida do datasource no schema.prisma → solução: `prisma.config.ts` + `@prisma/adapter-pg`
- **shadcn asChild:** Base UI não suporta → usar `render` prop ou `<a>` direto com classes
- **Next.js 16 middleware:** renomear para proxy.ts
- **NextAuth types:** criar `src/types/next-auth.d.ts` para estender Session com `plan`, `role`, `xp`, `level`
