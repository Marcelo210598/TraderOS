## Problema NÃO resolvido — integração NinjaTrader

O usuário instalou o NinjaScript no NinjaTrader 8 e o indicador **compilou e está rodando** no gráfico (header mostra "TraderOS Sync(...)"). Mas:
- A Saída NinjaScript fica **vazia** mesmo com `Print()` no código
- Trades não chegam ao endpoint `/api/sync/ninjatrader` (verificado por logs do Vercel)
- O `State.Active` parece não estar executando os Print's

### Hipóteses para amanhã
1. **State.Active não dispara** quando indicador é adicionado sem dados históricos prontos. Solução: mover lógica para `State.DataLoaded` ou `State.Realtime`
2. **Account.All vazio** quando State.Active roda. Solução: usar `Account.AccountStatusUpdate` event global
3. **Indicators têm restrições para chamadas HTTP/threading.** Solução: refazer como **Strategy** (não Indicator) — strategies têm `OnExecutionUpdate` como override nativo, mais confiável

### Caminhos sugeridos para amanhã
- **Plano A:** Reescrever como `Strategy` (não Indicator). Strategy tem `OnExecutionUpdate()` override nativo. Mais robusto.
- **Plano B:** Fallback CSV automatizado — script Python que monitora pasta de export do NT8 e faz POST para o TraderOS
- **Plano C:** Webhook do NT8 (se existir nativo) ou usar CrossTrade API
