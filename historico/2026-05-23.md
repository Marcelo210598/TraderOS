## ⚠️ Problemas encontrados e soluções
- **`npm error Invalid Version:`** → `package-lock.json` tinha `@unrs/resolver-binding-openharmony-arm64` com `version: null`
- **Todos os tipos Prisma virando `any[]`** → `prisma generate` não rodava no build do Vercel
- **404 em todas as rotas após build ok** → `vercel.json` sem `framework: nextjs`
- **Login travando (spinner infinito)** → 2 queries Prisma + bcrypt no cold start > 10s timeout
- **`Email já cadastrado`** → conta foi criada numa sessão anterior; resetada via `UPDATE users SET password=...`
