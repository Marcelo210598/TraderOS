### Fix crítico: login em produção
- `src/auth.ts` — eliminada segunda query Prisma no callback `jwt`
- Antes: `authorize()` buscava user, `jwt()` fazia SEGUNDA query para plan/role/xp/level
- Depois: tudo numa única query em `authorize()`, `jwt` apenas lê o objeto em memória
- Resultado: login parou de travar no cold start do Vercel (timeout de 10s)

### Fix crítico: env vars com `\n` no Vercel
- TODAS as variáveis de ambiente tinham `\n` no final (criadas com `echo` em vez de `printf`)
- Isso quebrava: Google OAuth (401 invalid_client), logout URL corrompida, UploadThing, Resend, Anthropic
- Solução: removidas e recriadas todas usando `printf "valor" | vercel env add ...`

### Fix: logout "This page couldn't load"
- `<form action={serverAction}>` dentro de `DropdownMenuItem` gerava HTML inválido (button-in-button)
- Substituído por `<a href="/api/logout">`
- Criada rota `src/app/api/logout/route.ts` — `signOut({ redirect: false })` + redirect para `/login`

### Fix: Google OAuth loop (voltava para login sem autenticar)
- Causa: `OAuthAccountNotLinked` — email já existia via credentials, Google bloqueava o link
- Solução: `allowDangerousEmailAccountLinking: true` no Google provider em `src/auth.ts`
- JWT callback atualizado para buscar plan/role/xp/level no DB quando fluxo for OAuth

### Fix TypeScript (build Vercel)
- `src/app/(app)/checkin/page.tsx` — anotações explícitas nos callbacks `.some()` e `.map()`
- `src/components/layout/header.tsx` — removido `asChild` (Base UI não suporta essa prop)

## ⚠️ Problemas encontrados e soluções
- **`npm error Invalid Version:`** → `package-lock.json` tinha `@unrs/resolver-binding-openharmony-arm64` com `version: null`
- **Todos os tipos Prisma virando `any[]`** → `prisma generate` não rodava no build do Vercel
- **404 em todas as rotas após build ok** → `vercel.json` sem `framework: nextjs`
- **Login travando (spinner infinito)** → 2 queries Prisma + bcrypt no cold start > 10s timeout
- **`Email já cadastrado`** → conta criada em sessão anterior; resetada via `UPDATE users SET password=...`
- **`\n` em env vars** → quebrava TUDO silenciosamente (Google 401, URLs inválidas, APIs falhando)
- **Logout "This page couldn't load"** → HTML inválido por button-in-button no DropdownMenuItem
