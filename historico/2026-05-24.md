## 📝 Decisões técnicas importantes
- **Prisma 7 + sandbox:** `prisma generate` não roda no sandbox → usar `(prisma as any).notification` / `(prisma.trade as any)` enquanto o cliente não é regenerado no Vercel
- **Migrações manuais:** padrão estabelecido — arquivo SQL + endpoint temporário `GET /api/admin/apply-*` com secret, delete após confirmação
- **Cron Vercel:** configurado em `vercel.json` com `"crons"`, autenticado via header `Authorization: Bearer CRON_SECRET`
- **accountLabel padrão "PA":** trades antigos sem label recebem "PA" por default, pode ser reclassificado em massa via /journal/contas

## ⚠️ Problemas encontrados e soluções
- **`url = env("DATABASE_URL")` no schema.prisma:** Prisma 7 não suporta mais isso no schema, a URL vai só no `prisma.config.ts`. Causou falha de build no Vercel (P1012). Removido.
- **404 no Vercel:** usuário acessou URL de deployment antigo que falhou. O deployment correto era `trader-os-ashy.vercel.app`
- **Migração apply rodada no console.neon.tech:** usuário confundiu o painel do Neon com a URL do app. Corrigido com a URL exata.
- **`prisma.notification` TS error:** mesmo padrão do accountLabel — cast `(prisma as any).notification`
