## 📝 Decisões técnicas importantes

- Radial gradient aplicado via `background-image` inline no CSS do `body` (não via Tailwind) porque Tailwind não suporta `background-attachment: fixed` com gradientes customizados diretamente.
- Para o box-shadow do XP bar fill, usado `style` inline porque Tailwind `shadow-*` não gera o glow neon com cor oklch diretamente.
- Todos os 7 itens foram confirmados visualmente via Playwright + screenshot em produção antes de avançar.

## ⚠️ Problemas encontrados e soluções

- **node_modules corrompido localmente** — pacotes como `find-up/package.json` e `semver/package.json` dentro de `next/dist/compiled/` tinham JSON incompleto, causando `ERR_INVALID_PACKAGE_CONFIG` em Node 22. Solução: `rm -rf node_modules && npm install --cache /tmp/npm-cache-traderos`.
- **npm cache sem permissão** — `EACCES: permission denied, rename` no cache padrão do npm. Solução: usar `--cache /tmp/npm-cache-traderos` para evitar o cache root.
- **Playwright não acessa localhost** — o browser do MCP roda em sandbox e não consegue acessar `http://localhost:3000`. Solução: testar sempre via deploy Vercel.
