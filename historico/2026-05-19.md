## 📝 Decisões técnicas
- Guardian é 100% client-side (sem DB) — cálculos em `useMemo`, zero latência
- PnL calculado automaticamente no formulário com base no par de preços + point value por ativo
- Planos: botões de assinatura ainda sem gateway de pagamento (próxima sessão)
- Cadastro: hash bcrypt strength 12 (seguro e razoável em termos de tempo)
- JWT session: o plano/role são lidos do DB no callback `jwt` e cacheados no token — ao mudar plano o usuário precisa re-logar para o JWT refletir

## ⚠️ Problemas encontrados e soluções
- JWT cacheado após atualizar plano no DB → solução: logout + login forçado. Para produção considerar `session.update()` do NextAuth ou invalidar manualmente
- Shadcn Base UI não tem `asChild` → usar classes diretamente em `<a>` ou `render` prop nos botões
