## 📝 Decisões técnicas importantes
- **Link de Pagamento (não customer+subscription):** o Asaas exige CPF/CNPJ pra criar cobrança direta. O Link recorrente joga a coleta de CPF/forma de pagamento pra página hospedada do Asaas → menos fricção e a gente não armazena PII. Mapeamento de volta via `externalReference`.
- **`externalReference="userId|PLAN|CYCLE"`:** o webhook decodifica e sabe exatamente qual plano liberar, sem ida ao banco. Propaga do link pras cobranças geradas.
- **Enum NÃO renomeado:** mantido `TRADER` no banco (UI mostra "Starter"). Evita migration de enum num banco gerenciado por `db push`. Zero risco.
- **`accessSource`:** webhook nunca rebaixa quem é MANUAL (comunidade Nômade liberada na mão pelo admin).
- **Webhook sempre 200:** erros são logados mas devolvem 200 pro Asaas não reenfileirar/pausar a fila.

## ⚠️ Problemas encontrados e soluções
- **Erro TS no `body` do fetch:** `RequestInit & { body?: unknown }` colidia com o tipo `BodyInit`. Solução: `Omit<RequestInit, "body"> & { body?: unknown }`.
- **Webhook dava 401 mesmo com token certo:** o `proxy.ts` bloqueia toda `/api/*` sem sessão. Solução: adicionar `/api/asaas/webhook` ao `PUBLIC_API_PREFIXES` (só o webhook, não o checkout).
- **`const URL` no script de teste** sombreava o `URL` global → renomeado p/ `WEBHOOK_URL`.

### 🚨 BUG ENCONTRADO E CORRIGIDO — API key com `$` era zerada
- A `ASAAS_API_KEY` começa com `$` (`$aact_hmlg_...`). O **Next.js faz expansão de variáveis** (`$NOME` → outra var → vazio), zerando a key **tanto no `.env` local quanto nas env vars do dashboard da Vercel**. Sintoma: checkout retornava "Pagamento não configurado no servidor" (`isAsaasConfigured()` falso).
- **Correção:** escapar o cifrão como `\$aact_...` no `.env` E na Vercel. Depois disso a key passou a ser lida (166 chars). **Confirmado via rota de debug temporária** (já removida).
- ⚠️ **Quando trocar pra key de PRODUÇÃO (`$aact_prod_...`), escapar de novo (`\$`).**

### Outros aprendizados
- **Token do webhook precisa ter ≥32 chars** (Asaas rejeita menor). O antigo tinha 28 → gerado novo de 48 chars (atualizado no `.env` e na Vercel).
- Webhook criado via API (`POST /webhooks` sandbox) → `https://trader-os-ashy.vercel.app/api/asaas/webhook`, 6 eventos. Continua válido pra produção (mesma URL).
- Conta **sandbox é separada da produção** no Asaas.

### Config aplicada na Vercel (Production)
- `ASAAS_ENV=sandbox`, `ASAAS_API_KEY=\$aact_hmlg_...` (escapado), `ASAAS_WEBHOOK_TOKEN=<48 chars novo>`.
